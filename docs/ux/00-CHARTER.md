# UX — Charter

## Mission

Own navigation, information architecture and interaction flow: how a visitor moves through Rive Webworks and why the flow is structured that way.

## Authority

UX/content structure and visual review sit with Claude for proposal and review; Silvester Odilu holds final authority (`docs/governance/AUTHORITY.md`, row "UX/content structure and visual review").

## Responsibilities

- Record the intended navigation and interaction structure, and the reasoning behind it, so implementation does not depend on chat memory.
- Review implemented flows against the recorded structure and report defects.
- Route interaction/flow refinements here per `docs/OFFICES.md` § Refinement-ownership routing.

## Inputs

- Silvester's direction on structure and priorities.
- Existing implementation in `src/app`, `src/features`.
- User-testing or review feedback, when available.

## Outputs

- UX/flow decisions recorded in this office (added here as they occur; none predate this charter).
- Defect reports on navigation/interaction gaps.

## Approval authority

Silvester Odilu.

## Implementation ownership

Codex (or the sole implementation writer recorded in `docs/governance/EXECUTION_STATE.md`) implements; Claude reviews.

## Dependencies

`docs/governance/AUTHORITY.md`, `docs/governance/EXECUTION_STATE.md`, `docs/OFFICES.md`.
